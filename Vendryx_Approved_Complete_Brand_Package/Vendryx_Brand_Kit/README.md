# Vendryx Complete Brand Kit

**Approved direction:** third revised Vendryx logo (folded orange wing/ribbon on charcoal).

**Source of truth:** fully scalable, self-contained SVG exports; the raster PNG sizes are renderings of these SVG sources. SVG wordmarks contain outlined glyphs so they work without installing a font.

## Structure

- `01_Primary_Logos/`: light/dark horizontal logos, with and without Syed Systems signature, transparent PNG and SVG.
- `02_Secondary_Logos/`: vertical stacked lockups.
- `03_Wordmark/`: Vendryx-only and Vendryx with signature.
- `04_Symbol/`: standalone ribbon / lettermark, light/dark app tiles, monochrome options.
- `05_Favicons/`: .ico, scalable favicon.svg, 16-96 px PNG exports.
- `06_App_PWA/`: iOS/Android/PWA 180-1024 px, maskable icons and manifest.
- `07_Social_Marketing/`: LinkedIn/Facebook/X/YouTube social covers; OG/GitHub previews; social avatars; brand backgrounds, SVG and PNG.
- `08_Guidelines/`: brand identity guidelines PDF and Markdown.
- `09_Developer/`: CSS and JSON tokens, example Tailwind tokens, Next.js example, implementation steps.
- `10_QA/`: asset inventory, dimensions, transparency, hashes, and preflight report.
- `11_References/`: original approved mockup and four visual concept presentation boards (not standalone production masters).
- `12_Source/`: build script and rebuild notes.
